## Summary

Data were gathered on 2026-09-03 by fetching primary pricing pages, pricing APIs, cloud docs, an SEC filing, NVIDIA architecture pages, and arXiv papers (the session's WebSearch quota was exhausted, so all evidence comes from direct fetches). H100 80GB on-demand prices span roughly $1.73 (Vast, aggregator) to $12.29/GPU-hr (Azure ND96isr_H100_v5 eastus list): Lambda $3.99-4.29, RunPod $3.29 secure / $2.69 community, Nebius $3.85, Modal ~$3.95, Crusoe $3.90, DigitalOcean $4.41, CoreWeave $6.155, AWS $6.88 on-demand / $5.191 Capacity Block, GCP $11.06 (us-central1). H200: Nebius $4.50, RunPod $4.59, Crusoe $4.29, Modal ~$4.54, CoreWeave $6.305, AWS $7.91 on-demand, Azure $10.60. B200: Lambda $6.69-6.99, RunPod $6.79, Nebius $7.15, Modal ~$6.25, CoreWeave $8.60, AWS $14.24 on-demand / $12.355 Capacity Block. GB200: CoreWeave $10.50/GPU-hr (4-GPU NVL72 instance), AWS P6e Capacity Block $10.582, Azure ND GB200 v6 $108.16/hr for a 4-GPU VM. MI300X: Hot Aisle $2.99 (bare-metal reserved $3.39), DigitalOcean $2.59, Crusoe $3.45, Azure $6.00 list; MI325X: DigitalOcean $3.80. L40S: RunPod $0.99, Crusoe $1.50, DigitalOcean $1.57, Nebius $1.55-1.82, AWS g6e.xlarge $1.861. A100 80GB: RunPod $1.39-1.59, Crusoe $2.00-2.30, Modal ~$2.50, CoreWeave $2.70, Lambda $2.79, AWS p4de $3.43. Spot/preemptible: AWS p5 $2.59, p5en $3.39, p6-b200 $5.24/GPU-hr (57-63% off); GCP a3-high $6.64, a3-mega $3.69 (40-68% off); Azure H100 Spot $2.37 (81% off) while Azure H200 Spot meters equal list price; Azure MI300X Spot $1.33; Nebius preemptible H100 $2.15, H200 $2.45, B200 $3.95; Vast interruptible bids 50-80% off; SF Compute shows $1.90 average GPU-hr. Notice windows: AWS 2 minutes best-effort; GCP 0 s default or 120 s preview; Azure 30 s best-effort; Vast none stated. AWS and Azure publish banded/hourly eviction-rate histories; no GPU-pool rates were retrievable. Host RAM proxies: AWS ~$0.0036/GiB-hr on-demand (~$0.0018 Spot), GCP ~$0.0042/GB-hr, Modal $0.008/GiB-hr. Local NVMe proxies: ~$0.0001/GB-hr (AWS i4i/i7ie deltas), Nebius $0.065/GiB-month, RunPod $0.10/GB-month. Bandwidths: PCIe Gen5 x16 128 GB/s (H100 spec); NVLink-C2C 900 GB/s bidirectional (GH200 and GB200), Grace LPDDR5X 480-512 GB at 512-546 GB/s. CoreWeave Q2 2026 revenue $2,575M vs cost of revenue $879M (Q2 2025: $1,212M vs $313M). Production traces: Acme median GPU utilization 97-99% with ~40% SM activity vs PAI 4% and Philly 48%; Azure inference traces show conversation batches running 20 or fewer tokens 60-70% of the time.
