# Research: Long-running / idle-gapped agent infrastructure as of 2026: coding agents, computer-use agents, agent runtimes and durable execution, human-in-the-loop approval patterns, scheduled/async agents, prompt caching on resume, session-persistent inference, and open-model usage in agent products

## Summary

Public telemetry on long-running agents in 2026 comes from a handful of sources. Anthropic reports ~400k Claude Code sessions averaging about four user turns with ~10 actions per prompt, a median turn of ~45 s, and a 99.9th-percentile turn that grew from under 25 min to over 45 min between Sept 2025 and Jan 2026. The TraceLab study (June 2026, ~4,300 Claude Code/Codex sessions) gives the most granular picture: median prefix ~116–126K tokens per step, ~860 new input tokens, ~200–250 output tokens, a median human gap of 1.4 min (p90 20.6 min), and 95.7% prefix-cache hits overall but only 84.4% on user-initiated steps. vLLM/Mooncake's Codex traces show ~131:1 input:output and 5 s median / 81 s P99 tool-driven inter-turn gaps.

Cache handling on resume is governed by provider TTLs: Anthropic's 5-minute default and 1-hour option (2x write price), OpenAI's 30-minute (GPT-5.6+) or 24h retention, DeepSeek's hours-to-days disk cache, Fireworks' per-replica cache with session-affinity headers. Claude Code requests the 1-hour TTL only for subscription users within plan usage, and a public issue documents a TTL regression in March 2026 with 17% measured cost inflation; a Codex issue documents total cache misses on Azure past ~150K tokens. After a gap longer than the TTL, Claude Code recomputes the full prefix and may offer resume-from-summary.

Hosted agent products meter idle time differently: Managed Agents bills $0.08/session-hour only while running; Devin sleeps after ~0.1 ACU of inactivity; AgentCore idles out at 15 minutes by default with 8-hour microVM lifetimes; Codex caches container state 12 hours; Claude Code web reclaims idle VMs and restores history on reopen. Durable-execution runtimes (Temporal, Inngest, LangGraph, DBOS) wait indefinitely for approvals at no compute cost; the Claude and OpenAI Agent SDKs serialize paused state for cross-process approvals. Scheduled agents exist as Claude Code Routines, Managed Agents deployments, and Codex automations.

No provider was found selling guaranteed session-pinned KV retention; open-source work (SGLang KV hints, vLLM agentic-api routing, LMCache, Mooncake, Continuum) targets that gap. Open-weight models carry a majority of OpenRouter tokens by mid-2026; Cursor's Composer 2 is built on Kimi K2.5, Browser Use ships a 30B open model, OpenHands recommends Qwen3.6-35B-A3B on vLLM/SGLang, and Cognition serves proprietary SWE-1.6 on Cerebras.
